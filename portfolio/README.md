# Gift Seilane portfolio

A static, responsive portfolio for Benedict Gift Seilane. It showcases the projects from the supplied CV and links directly to the matching public GitHub repositories. No build tools or dependencies are required.

## Preview

Open `index.html` in a browser, or serve this folder locally with any static web server.

## Publish with GitHub Pages

The `Deploy portfolio` GitHub Actions workflow publishes this folder whenever it changes on `main`. The public site URL is:

<https://43011144.github.io/TapasBar/>

The first workflow run may require GitHub Pages to be enabled for the repository with **GitHub Actions** selected as the source in **Settings → Pages**.

## LinkedIn cover

`assets/linkedin-cover.png` is the 1584 × 396 upload-ready banner for the LinkedIn profile header. `assets/linkedin-cover.svg` is the editable vector source.

## Profile copy

`linkedin-copy.md` contains copy-ready headline, About text and project descriptions for the LinkedIn profile.
